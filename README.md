# Youssef Ayman Portfolio

Personal portfolio website for Youssef Ayman, built with plain HTML and CSS.

## Overview

This project is a clean, responsive portfolio landing page that presents a profile hero, about section, skills grid, featured projects, and contact links. It uses a background video and glass-style panels to give the page a modern visual identity.

## Features

- Responsive layout for desktop and mobile
- Full-screen background video
- Hero section with profile image and call-to-action buttons
- About section with experience stats
- Skills cards for frontend, backend, database, and tools
- Featured projects showcase
- Social links in the footer

## Tech Stack

- HTML5
- CSS3

## Project Structure

- `index.html` - Main page content
- `style.css` - Core styles
- `media.css` - Responsive styles
- `image/` - Images and logo assets
- `video/` - Background video assets

## How to Run

1. Open the project folder in VS Code or any editor.
2. Open `index.html` in a browser.
3. Make changes in `style.css` and `media.css` if you want to customize the design.
